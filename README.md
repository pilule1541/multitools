# 🛠️ MultiTools

Un outil tout-en-un regroupant plusieurs fonctionnalités utiles dans une seule application.

## ✨ Fonctionnalités

- 🔐 Générateur de mots de passe
- 🌐 Outils réseau (IP Lookup, Ping, DNS...)
- 📁 Gestion de fichiers
- 🔒 Chiffrement / Déchiffrement
- 📊 Encodeurs & Décodeurs (Base64, Hex...)
- 🧮 Calculatrices
- 📝 Générateur de texte
- ⚡ Automatisation de tâches
- 🛡️ Outils de sécurité
- 🔧 Utilitaires système

## 🚀 Installation

```bash
git clone https://github.com/tonpseudo/multitools.git
cd multitools
```

## 📸 Aperçu

> Une interface moderne regroupant tous les outils au même endroit.
